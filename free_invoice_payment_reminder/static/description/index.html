🚀 How It Works

  1. Install & Configure: Set your preferred reminder schedule (default: 3, 7, 14 days overdue)
  2. Automatic Monitoring: System checks for overdue invoices daily
  3. Smart Reminders: Sends appropriate reminder based on how many days overdue
  4. Track Results: View reminder history and payment status in your dashboard

⚙️ Configuration Options

  • Set custom reminder intervals (e.g., 5, 10, 15 days overdue)
  • Customize email templates with your branding
  • Configure sender email address
  • Enable/disable reminders per company (multi-company support)
  • Choose which invoice types receive reminders

📋 Requirements

  • 18.0
  • Accounting module installed
  • Configured email server (for sending reminders)

🛠️ Installation & Setup

  1. Install the module from Apps menu
  2. Go to Accounting → Configuration → Payment Reminder Settings
  3. Configure your reminder schedule and email settings
  4. That's it! The system will start monitoring automatically
